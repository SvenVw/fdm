Users can now only select cultivation codes that are available for the relevant year in RVO Basisregistratie Percelen. This removes unnecessary options from cultivation selection combo boxes and makes entering correct data easier. Existing cultivations stay as they are and can be part of calculations, however the user sees a warning on the field dashboard and the cultivation details page that the cultivation code is not allowed by RVO in the given time period.
